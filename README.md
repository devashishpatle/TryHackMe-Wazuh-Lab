## 📌 About The Lab

This repository documents my hands-on learning and successful completion of the **Wazuh room on TryHackMe**.

Wazuh is an open-source SIEM and security monitoring platform used for vulnerability detection, log analysis, security event monitoring, and compliance auditing.

All practical activities were performed within the TryHackMe lab environment.
